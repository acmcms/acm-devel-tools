# acm-devel-tools

A developer's local toolkit for working with `acmbsd` (the FreeBSD automation tool from `acm-install-freebsd`) and packaging AxiomCMS releases: `acm-commands.txt` is a personal cheat-sheet of `acmbsd update`/`restart` invocations, `EXPORT-MAKE-SYS-{CURRENT,RELEASE}.xml` are export/build definitions, `defaults/` holds default settings/resources/packages for new projects, `contact/` has branding assets, and `import/` bundles a third-party Swing layout jar (MigLayout) for some GUI dev tool.
